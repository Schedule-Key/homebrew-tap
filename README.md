# FoxChief for Homebrew

[FoxChief](https://foxchief.com/) is a native Mac workspace for terminal and AI-agent work. Apple silicon, macOS 14 or later.

```bash
brew install --cask schedule-key/tap/foxchief
```

FoxChief updates itself (the cask says `auto_updates true`), so `brew upgrade` leaves it alone. To remove
everything it keeps, use Settings ▸ Advanced ▸ Uninstall FoxChief… first, then `brew uninstall --cask --zap foxchief`.

This tap is written by FoxChief's release; please report problems at https://foxchief.com/support.
